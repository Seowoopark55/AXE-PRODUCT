# AXE PRODUCT STAGING · 3.26.1

## 3.26.1 · First-run Member Registration Gate

회사 미확인 계정에게 합류 코드를 주는 대신, 기존 회사 팀원은 대표/관리자의 선등록이 완료될 때까지 대기하도록 변경했습니다. `등록 확인하기`가 Discord ID 기반 placeholder membership을 다시 확인하고, 등록된 경우에만 소속 회사로 진입합니다. 신규 대표는 `새 회사 등록 시작`에서 기존 Guided Setup으로 이어집니다.

> 3.26.1은 **WEB 수정**입니다. 3.26.0의 membership claim SQL을 이미 적용했다면 추가 SQL/BOT 배포는 없습니다.

3.26.0은 첫 로그인 직후의 신규 이용 흐름을 정리한 온보딩 업데이트입니다. 회사가 없는 계정은 별도 메뉴를 찾지 않고 바로 새 회사 생성 또는 기존 회사 합류를 선택할 수 있습니다.

## 3.26.0 · First-run Onboarding
- 회사 생성 화면에서 `SLUG` 입력을 완전히 숨겼습니다. 내부 식별값은 브라우저가 자동 생성해 `create_company`에 전달하므로 이용자는 볼 필요가 없습니다.
- 새 회사는 `회사 이름 입력 → 회사 생성 → Discord Guided Setup`으로 끊김 없이 이어집니다.
- 초기설정 중 나간 OWNER는 다음 로그인 때 저장된 단계부터 자동 재개합니다.
- 초기설정에서 Discord ID로 미리 등록된 멤버는 첫 로그인 때 `web_claim_discord_memberships()`가 auth 계정과 자동 연결합니다.
- 이미 등록된 일반 멤버/관리자는 회사 생성 화면과 초기설정을 보지 않고 소속 회사로 바로 진입합니다.
- 아직 멤버 등록이 안 된 팀원은 첫 화면의 `기존 회사에 합류`에서 회사 합류 코드를 입력할 수 있습니다.
- 멤버 관리에 `회사 합류 코드` 생성 버튼을 추가했습니다. 생성 코드는 7일 / 최대 50명 기준입니다.
- 이미 등록된 멤버는 합류 코드가 필요 없다는 안내를 함께 표시합니다.

> 3.26.0은 **SQL + WEB** 업데이트입니다. BOT 변경은 없습니다. LIVE BOT은 대상이 아닙니다.

# AXE PRODUCT STAGING · 3.25.4

3.25.4는 3.25.3의 한눈에 보이는 대시보드 구조를 그대로 유지하면서, 실제 운영 화면에서 너무 작게 보이던 대시보드 전용 글자 크기와 보조문구 명도를 올린 WEB 전용 업데이트입니다.

## 3.25.4 · Dashboard Readability
- KPI 라벨 / 값 / 보조문구를 단계별로 확대했습니다.
- `지금 확인할 것`, `빠른 실행`, `최근 활동`, `운영 연결 상태`의 제목과 설명을 모두 키웠습니다.
- NOW / QUICK ACTION / ACTIVITY / OPERATIONS 같은 보조 라벨도 멀리서 바로 읽히도록 확대했습니다.
- 운영 스냅샷, 날짜, 상태, 사용 중 기능 태그처럼 가장 작았던 텍스트도 9px대 이상으로 올렸습니다.
- 작은 회색 글씨의 명도를 한 단계 높여 크기뿐 아니라 대비도 개선했습니다.
- 기존 2열 정렬 / 같은 행 높이 / 한 화면 중심 / 대시보드 내부 무스크롤 원칙은 그대로 유지합니다.

> 3.25.4는 WEB 전용입니다. 추가 SQL/BOT 배포는 없습니다. LIVE는 대상이 아닙니다.

# AXE PRODUCT STAGING · 3.25.3

3.25.3은 3.25.2의 정렬 구조를 유지하면서, 데스크톱 대시보드 아래에 남던 큰 외부 공백을 줄이는 WEB 전용 업데이트입니다.

## 3.25.3 · Full Canvas Dashboard
- 대시보드 2열 매트릭스가 현재 viewport의 남는 세로 공간을 자동으로 사용합니다.
- 같은 행의 카드 하단선은 계속 정확히 맞춥니다.
- 최근 활동이 0~2건이면 남는 공간에 `운영 스냅샷`을 표시합니다.
- 운영 스냅샷은 기존 데이터만 재사용합니다: 불러온 공금 내역 / 자산 반납 기록 / 처리 대기 / 사용 중 기능.

- 좁은 화면에서는 자동 높이로 복귀해 모바일/태블릿 세로 스크롤 충돌을 막습니다.

# AXE PRODUCT STAGING · 3.25.2

3.25.2는 3.25.1의 기능을 그대로 유지하면서 대시보드의 오와열과 화면 밸런스를 다시 정돈한 WEB 전용 업데이트입니다.

## 3.25.2 · Balanced Command Center

- 대시보드 폭을 현재 콘텐츠 레일에 맞게 확장해 좌우의 애매한 빈 공간을 줄였습니다.
- `지금 확인할 것 / 빠른 실행`과 `최근 활동 / 운영 연결 상태`가 하나의 고정 2열 그리드에 정확히 맞춰집니다.
- 같은 행의 카드 높이를 강제로 동일하게 맞춰 박스 하단선이 어긋나지 않습니다.
- `지금 확인할 것`은 최대 4개만 노출하고 추가 항목은 숫자로 요약해 대시보드가 길어지지 않습니다.
- ALL CLEAR 상태는 단순 빈 공간 대신 공금 검수 / 계좌 검수 / 지원 응답 / 미배정 자산을 한 줄로 보여줍니다.
- 빠른 실행의 중복 안내 문구를 제거하고 2×2 액션 영역 자체가 카드 높이를 균형 있게 채웁니다.
- 최근 활동은 최대 4건을 유지하고, 운영 연결 상태는 Discord + 사용 기능을 같은 높이 안에서 정돈합니다.
- 데스크톱 대시보드 내부에는 별도 세로 스크롤을 만들지 않습니다.

> 3.25.2는 WEB 전용입니다. 추가 SQL/BOT 배포는 없습니다. LIVE는 대상이 아닙니다.

# AXE PRODUCT STAGING · 3.25.1

3.25.1은 3.25.0 기능을 모두 유지하면서 대시보드를 한 화면 중심으로 다시 정돈한 WEB 전용 업데이트입니다.

## 3.25.1 · 대시보드 한눈에 정돈
- 빠른 실행을 공금 등록 / 멤버 관리 / 자산 추가 / 계좌 관리의 핵심 운영 액션으로 정리
- 회사 설정은 작은 헤더 바로가기로 이동
- 질문게시판 / 건의게시판은 좌측 지원 메뉴와 알림 영역으로 역할 분리
- `지금 확인할 것`을 2열 컴팩트 카드로 재배치
- 최근 활동 4건 제한
- 데스크톱 대시보드 전체 밀도를 줄여 세로 스크롤 발생을 억제
- **WEB 전용 패치이며 추가 SQL/BOT 변경 없음**

## 지원 구조
- `질문게시판`: 같은 회사 멤버가 질문/답변을 함께 볼 수 있는 회사 FAQ형 지원 공간
- `건의게시판`: **작성자 본인과 PLATFORM OWNER만 볼 수 있는 1:1 비공개 공간**
- 두 게시판 모두 답변은 PLATFORM OWNER만 등록
- Discord는 답변 알림용이며 사이트 데이터의 원본은 `axe_product` DB

## 건의게시판
- 개선 제안 / 오류 제보 / 기타
- 답변대기 / 확인중 / 답변완료
- 사용자에게는 자기 글만 노출
- 5건/페이지
- 답변 도착 `NEW` 표시
- 작성자 추가 메시지 → 답변대기로 재전환
- 작성자/PLATFORM OWNER 삭제
- 작성 후 상세창 자동 재오픈 없음
- 수동 `회신 Discord` 입력 없음

## 첨부사진
- 파일 선택 / Drag & Drop / Ctrl+V 붙여넣기
- JPG · PNG · WEBP
- 장당 10MB / 메시지당 최대 5장
- 앱 내부 이미지 크게보기
- private bucket `axe-suggestion-attachments`

## PLATFORM OWNER
서비스 관리 화면에서:
- 고객 질문 Queue
- 비공개 건의 · 제보 Queue
를 각각 확인합니다.

답변 등록 시 사이트 NEW 표시를 남기고, 작성자의 현재 연결 Discord ID로 DM을 시도합니다. DM 실패는 답변 흐름에 영향을 주지 않습니다.

## 배포 순서
1. WEB ZIP을 압축 해제해 GitHub AXE PRODUCT WEB STAGING 프로젝트에 전체 덮어씁니다.
2. commit / push 합니다.
3. Vercel STAGING 상태가 `Ready`인지 확인합니다.

> 3.25.1은 WEB 전용입니다. 3.25.0 DB migration이 이미 적용된 현재 STAGING 기준으로 추가 SQL/BOT 작업은 없습니다. `apply-axe-product.sh`를 사용하지 않습니다. LIVE BOT/WEB은 대상이 아닙니다.

## 기존 migration 전제
기존 STAGING DB에는 사용 중인 이전 migration(질문게시판 3.23.x, 핀볼 3.24.0 등)이 적용된 상태를 유지하고, 이번에는 3.25.0 migration만 추가 적용합니다.
