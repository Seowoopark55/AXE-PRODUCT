AXE PRODUCT WEB STAGING 3.17.0 — DENSE OPERATIONS ROOT REDESIGN

Scope: WEB STAGING only. DB/BOT/LIVE untouched.

Root causes removed:
- Management pages had accumulated three different layout contracts: old grid rows,
  compact refinements, and semantic table overrides.
- Per-page workspaces used different width assumptions, so the same information
  density produced different visual rhythm.
- table-layout:fixed solved axis alignment but introduced squeezed text and did not
  reproduce the compact Company Settings visual language.
- repeated secondary labels increased row height and made sparse data feel emptier.

New design:
- Company Settings is the reference visual grammar and is not changed.
- Members / Assets / Accounts use one 680px operational workspace.
- All boards use the same toolbar / meta / lane header / 54px row rhythm.
- Header and data rows share the exact same CSS grid template per category.
- Standard 700/800 font weights replace interpolated 780/860/880 weights.
- Fund ledger keeps its existing functionality but switches from a stretched table
  to a compact 760px fixed-lane board; the entry lane receives the flexible width.
- Mobile collapses lane rows without relying on table display overrides.

No functional API/RPC changes.
